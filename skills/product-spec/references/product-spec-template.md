### ASCII 页面结构

```text
+--------------------------------------------------+
| SEC-PAGE-HEADER                                  |
| Breadcrumb  Page title              [Primary]   |
+--------------------------------------------------+
| SEC-FILTERS                                      |
+----------------------+---------------------------+
| SEC-NAVIGATION       | SEC-MAIN-CONTENT          |
|                      |                           |
+----------------------+---------------------------+
| SEC-PAGINATION                                   |
+--------------------------------------------------+
```

ASCII 用于表达 Section 的顺序、并列、嵌套、主要操作和必要的抽屉或弹窗关系，不要求像素级视觉稿。

### 特殊交互

仅描述 ASCII 难以表达的行为，优先使用：`触发 -> 系统响应 -> 结果或反馈`。

示例：

- 选择列表项后在当前页面打开详情抽屉。
- 关闭抽屉后保留筛选条件和滚动位置。
- 详情加载失败时保持抽屉打开并提供重试。
